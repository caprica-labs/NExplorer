NExplorer is a document reader, file manager and download manager in one app. No ads, no tracking, no accounts.

<b>Reader</b>
<ul>
<li>Opens PDF, EPUB, MOBI, FB2, XPS, CBZ and CBR comics, DOCX, DOC, PPTX, HTML and TXT.</li>
<li>Light and dark themes for the app and the page; scroll or page by page, vertical or horizontal; reflow for easier reading.</li>
<li>Highlight, underline, add text and signatures; every edit can be undone.</li>
<li>Bookmarks, table of contents and search.</li>
</ul>

<b>Explorer</b>
<ul>
<li>Browse internal storage and SD cards.</li>
<li>Copy, move, rename, hide, zip and extract (ZIP, RAR, 7z).</li>
<li>Recycle bin: deleted files are kept for 30 days.</li>
</ul>

<b>Tools</b>
<ul>
<li>PDF to Image, Text and Word; Image, Text and Word to PDF.</li>
<li>Merge, compress, lock, unlock and manage PDF pages.</li>
<li>Document scanner.</li>
<li>Network Share: send files between the phone and a computer on the same Wi-Fi, through a web page.</li>
</ul>

<b>Download manager</b>
<ul>
<li>Download files from direct links, or send a link to NExplorer from any app's share menu.</li>
<li>Shows the name and size before you start; choose the name and the folder.</li>
<li>Pause and resume, a queue you can reorder, and up to 5 downloads at once.</li>
<li>Up to 16 threads per download for faster speeds.</li>
<li>Daily scheduler: start and stop downloads at set times.</li>
<li>Retries on its own when a server or connection fails.</li>
<li>Encrypted (https) downloads only.</li>
</ul>
